How we help

Match identity to the application.

We review the application’s supported sign-in protocol, your Entra tenant, and who should have access. Depending on the application, integration may use OpenID Connect or SAML for sign-in, and OAuth 2.0 for API authorisation. Microsoft Graph access is scoped separately to the workflow and the permissions your tenant administrators approve.

What a project can include

  • An assessment of the application’s Entra ID integration requirements.
  • App registration or enterprise application configuration appropriate to the project.
  • SSO integration and testing of agreed user access and sign-in behaviour.
  • Scoped API permissions, configuration notes, and a handover for your administrators.

Planning your project

Tell us about the application, the sign-in experience you want, and any Microsoft APIs it needs. Your tenant administrator remains involved in approving access and permissions. We establish supported protocols and configuration responsibilities before making changes.

Useful questions

Is Entra ID the same product as Azure AD?

Microsoft renamed Azure Active Directory to Microsoft Entra ID. Older applications or setup instructions may still use the Azure AD name; we review the actual integration requirements.

Does single sign-on automatically give an app Microsoft Graph access?

No. Authentication and API permissions serve different purposes. Any Graph access needs the appropriate delegated or application permissions and consent, depending on the workflow and tenant policies.
